# 🎮 AI Minecraft Experiments

Добро пожаловать в архив моих экспериментов по созданию полноценной 3D-игры в стиле Minecraft с помощью Искусственного Интеллекта!

## 📌 О проекте
Здесь собраны разные версии игры, написанные в ходе увлекательных экспериментов: от простейшего процедурного мира и генерации ландшафта до умных зомби, системы голода, здоровья и деревень с жителями.

## 📂 Версии
* Версия с базовым миром и управлением.
* Версия с мобами (свинки, зомби) и инвентарем.
* Финальная версия с оптимизацией FPS, деревней и торговлей.
